## ✨ What it does

- Takes the **original logo** of every channel from your own picons and puts it on a new design.
- Choose **style**, **layout**, **size** and **language** inside the plugin, with a **live preview**.
- Works on **all satellites** and finds the real picon folder by itself.
- Missing logo? It borrows the same channel from another satellite, or draws a clean name tile.
- **Backup and one-key restore** of the original picons.

## 📦 Install (telnet)

Run this one command:

wget -q -O - https://raw.githubusercontent.com/mido00020/MohammedPicon/main/installer.sh | sh

It downloads the plugin, installs it and restarts the GUI.

## 🎛 Use

Extensions menu → **Mohammed Picon** → choose options → **Green: Apply**.
